# Telegram для БК анализ

Код и workflow подготовлены. Рассылка начнётся только после настройки двух Repository secrets. Токен не нужно отправлять в чат, добавлять в код или на сайт.

## 1. Создать бота

Откройте официальный [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username с окончанием `bot`. Сохраните выданный токен.

## 2. Подтвердить свой личный чат

На компьютере с Python запустите из папки проекта:

```powershell
python scripts/telegram_chat_id.py
```

Вставьте токен в скрытый ввод. Программа покажет username именно этого бота и одноразовую команду `/start bkliz-...`. Отправьте её боту в своём личном чате и нажмите Enter в программе. Она выведет ваш `TELEGRAM_CHAT_ID`. Если чат не подтверждён однозначно, программа остановится.

В этой рабочей папке команда выглядит так:

```powershell
python "C:\Users\Kislowj\.codex\.chatgpt-projects\g-p-6ad0e851040c8191b1019118e6acdac3\BKliz\scripts\telegram_chat_id.py"
```

## 3. Сохранить два секрета GitHub

Откройте [Settings → Secrets and variables → Actions](https://github.com/StLisovafk13/BKliz/settings/secrets/actions), нажмите **New repository secret** для каждого:

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `TELEGRAM_CHAT_ID` | Число из программы подтверждения чата |

Используйте отдельного нового бота для этого проекта. Workflow рассчитан на ваш личный чат; группы и каналы не подключаются автоматически.

## 4. Проверить отправку

Откройте [Actions → Telegram notifications](https://github.com/StLisovafk13/BKliz/actions/workflows/telegram.yml), выберите **Run workflow → main → Run workflow**. В Telegram придёт сообщение «БК анализ: уведомления подключены».

Без секретов workflow успешно проверит код и покажет в Summary, что ждёт настройки. Это ещё не подтверждение подключения Telegram.

## Какие сообщения приходят

- Новое событие из текущих отчётов трёх задач.
- Напоминание в течение часа до старта, если известны точные время и часовой пояс.
- Изменение счёта, подтверждённого итога прогноза, перенос или отмена.

Сообщения содержат событие, рынок, время ЕКБ, коэффициент из отчёта при наличии и ссылку на таблицу. Наблюдения сохраняют свою пометку. Бот читает опубликованные JSON, самостоятельно не проверяет спортивные результаты.

При первом подключении существующие события принимаются за исходное состояние: старые результаты и архив чатов не рассылаются. Напоминания для ближайших событий действуют сразу.

Проверка выполняется при изменении текущих feeds и по расписанию каждые 15 минут. GitHub Actions может запускать задания с задержкой; своевременная доставка до старта не гарантируется. Компьютер и вкладку сайта держать включёнными не нужно.

Отправленные уведомления запоминаются в GitHub Actions cache. При очистке/вытеснении cache или неопределённом сетевом сбое возможен повтор; абсолютная гарантия однократной доставки отсутствует. Не очищайте cache `telegram-v1-*` без необходимости.

Суммы и личный банк из браузера боту недоступны и в Telegram не отправляются. Для отключения: Actions → Telegram notifications → Disable workflow.

Официальные документы: [Telegram — создание бота](https://core.telegram.org/bots/tutorial), [Bot API](https://core.telegram.org/bots/api), [GitHub — запуск по расписанию](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).
