# BKliz Odds Collector — облачный пилот без VPS/API

## Назначение и ограничения

Это технический пилот Selenium в GitHub Actions. Он работает при выключенном компьютере пользователя и не требует API-ключа букмекера. Тестируется одна конкретная ссылка «Лиги Ставок» на матч «Амур — Салават Юлаев» 17 октября 2026, 10:00 МСК. Проверяется только доступность и видимость события на GitHub-hosted Chrome.

**Важно:** пилот НЕ подтверждает актуальные коэффициенты: всегда odds=null, price_verified=false и market_verified=false. Видимость команд не является подтверждением рынка. Нельзя рассчитывать EV, K0, условный банк или объявлять исход value. Для этого необходим отдельный адаптер конкретного рынка, который ещё предстоит проверить. Обхода CAPTCHA, авторизации и ограничений доступа нет.

## Файлы

- scripts/odds_collector.py — загрузка страницы Selenium и диагностические статусы.
- data/odds/targets.json — конфигурация одного точного URL, рынка и времени начала. После начала матча цель становится expired и браузер не открывается.
- data/odds/latest.json — последний статус проверки, без цен.
- .github/workflows/odds-collector.yml — ручной запуск и каждый час в 43-ю минуту UTC.
- tests/test_odds_collector.py — проверки допустимых источников, блокировки, видимости матча и отсутствия выдуманных цен.

## Ручная проверка

1. Откройте https://github.com/StLisovafk13/BKliz/actions/workflows/odds-collector.yml
2. Выберите Run workflow → main.
3. Просмотрите шаг Probe approved bookmaker event и скачайте артефакт odds-pilot-....
4. Если запись разрешена, диагностический JSON также появится в data/odds/latest.json.
5. Статусы: event_visible — две команды отображаются, но ни цена, ни рынок не подтверждены; event_not_verified — не видно двух участников; empty_page, redirected, blocked, source_error — источник недоступен или не проверен; expired — время старта уже наступило.

## Автоматическая проверка

Почасовое расписание GitHub Actions работает без компьютера и ChatGPT, но GitHub может задерживать или пропускать его. После однократной публикации истёкшей цели повторные коммиты не создаются, пока в targets.json не появятся новые будущие события. Пилот не изменяет data/feeds/cycle.json, другие feeds, архивы, pages.yml, telegram.yml и не размещает реальные ставки.

## Взаимодействие с единым циклом

ChatGPT может прочитать data/odds/latest.json, но пока это только диагностика, НЕ доказательство действующей котировки. После проверки рынка отдельный адаптер должен подтверждать матч, дату/время, период, порог, исход, цену, URL, timestamp и свежесть. Поиск либо видимые рядом с матчем числа не должны автоматически превращаться в коэффициенты.

Коммит через стандартный GITHUB_TOKEN не обязательно запускает другие workflows по push. Появление JSON в GitHub само по себе не подтверждает обновление сайта; для публикации цены на сайте понадобится отдельная интеграция.

## Локальный тест

  python -m unittest discover -s tests -p test_odds_collector.py -v
  python -m pip install 'selenium>=4.20,<5'
  python scripts/odds_collector.py

При ошибке Selenium источник получает статус source_error и workflow отмечается ошибкой. Доступность «Лиги Ставок» на IP-адресе GitHub-hosted runner пока неизвестна.
