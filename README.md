# БК анализ · BKliz

Журнал спортивных обзоров: таблица, поиск, фильтры, архив, время проверки источников. Сайт не размещает ставки. Исходные данные сохраняются в GitHub; публикация происходит только после проверки.

## Первое включение

В Settings → Pages → Build and deployment выберите Source: GitHub Actions. Затем в Actions → Validate and publish dashboard нажмите Run workflow. Адрес будет показан в успешном запуске Deploy.

## Обновление из задачи

Полный контракт и инструкция: [TASK_INSTRUCTIONS.md](TASK_INSTRUCTIONS.md). Перед изменением существующего latest.json необходимо прочитать его и использовать текущий blob SHA. Архивный файл создаётся первым; latest.json обновляется вторым. Повторный запуск с тем же run_id не должен создавать дубликат. Не удаляйте историю.

Проверка: `python scripts/validate.py`. Локальный просмотр: `python -m http.server 8000`.

Секреты не нужны для просмотра публичной таблицы. Для фоновой записи задача должна иметь разрешённый доступ к GitHub. Успешная ручная запись не доказывает доступ будущего фонового запуска.
